# Major Company Reference Cards (redrawn)

Ten reference cards recreated from `major_company.webp`, one per major
company: LNWR, Midland, LB&SCR, SE&CR, NER, GWR, Caledonian, L&YR, NBR,
and South Wales Railway.

Each card carries the company's name and brand color plus the shared
Trains and Treasury tables (identical across all ten companies in the
source photo). The tiny Home/Destination hex codes in the source photo
were not legible even at 8x upscaling, so those badges are left generic.

- `canvas.json` — layout/index for the set
- `*.dc.html` — one file per company, in the Design Component format
  used by the Claude Artifacts canvas type (needs that runtime's
  `support.js` to render; not standalone HTML)
